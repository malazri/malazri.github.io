Manual weather override

By default, weather is fetched live from Open-Meteo for Lekhwair's coordinates. Enable this only if the live feed is wrong (e.g. during a localized sandstorm) — override values below will be used instead.

Live sync pulls from the Ministry of Awqaf calendar. Browsers can't fetch that page directly (it isn't a public API and blocks cross-origin requests), so live sync needs a small server-side proxy — for example a Supabase Edge Function that fetches and parses the page, then this app calls your proxy. Until that's wired up, set today's times manually below.
